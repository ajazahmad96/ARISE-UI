Rank icons, one per rank, named rank-NN-slug.svg (NN = 01..11 in rank order).
Each is a glyph painted in the rank colour. Replace a file (keep its name) or edit RANK_ICON in js/data.js.
On the Roadmap/Level dialogs the glyph is shown white on a coloured tile (CSS filter), so keep it a single-shape glyph or change .rank-glyph--white in css/style.css.
